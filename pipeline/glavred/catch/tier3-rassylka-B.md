Ни одно утверждение ниже не следует принимать на слово — под каждым стоит команда,
которая его воспроизводит. Все запускаются из корня репозитория.

| утверждение | чем проверено |
|---|---|
| Каждая секция карты «в охвате» входит ровно в один фрагмент и прогнана каждым из пяти экстракторов ровно один раз | `python3 .superpowers/sdd/2026-08-13-glavred-skill/coverage_proof.py` — 0 дыр, 0 дублей, 0 чужих секций |
| Поле `anchor` каждой единицы — дословная подстрока названного файла-источника | `python3 .superpowers/sdd/2026-08-13-glavred-skill/verify_anchors.py` и независимо `ruby …/verify_anchors_ruby.rb` (настоящий YAML-парсер) |
| Источник берётся только из поля `source`, слаг в `id` ему не противоречит, якорь однозначен и лежит в одной строке | `ruby .superpowers/sdd/2026-08-13-glavred-skill/verify_anchors_strict.rb` |

## Как обращаться с якорем

Единицы ниже перенесены из рабочих файлов побайтово. Поле `anchor` — дословная
подстрока файла-источника, включая мягкие переносы `- ` внутри слова и неразрывные
пробелы U+00A0. **Нормализовать якорь нельзя, перепечатывать руками нельзя**:
проверка ведётся точным поиском подстроки, и оба этих действия её ломают, не меняя

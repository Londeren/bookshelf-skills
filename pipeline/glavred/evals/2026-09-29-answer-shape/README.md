# Смоук формы ответа скилла `glavred`, 2026-09-29

Проверка, на которой держится версия 0.2.0: два кейса эвал-набора прогнаны на 0.1.2 и на скилле с правилами выдачи, пересобранными по book-to-skill 1.1.1, по одному прогону на версию. Это смоук, а не перепрогон набора: два кейса, по одному образцу.

## Зачем

Ответ скилла ставил номер правила после каждой находки и каждой правки («Правило 1.21, 1.23.»), а слово «метод» без имени автора. У hormozi та же форма дала документ, который почти не читался. Book-to-skill 1.1.0 перенёс номера правил из тела ответа в блок «Основания» в его конце, а запрос оснований сделал сверкой с листами, а не новым поиском.

## Как прогоняли

- **Пересборка.** Отдельный сабагент на Opus прочитал book-to-skill 1.1.1 (SKILL.md и лист о форме вывода) и по нему одному переписал в копии 0.1.2 правила выдачи, список правок режима apply и ссылку на правило в абзаце о полях единицы. Он же добавил проверку самого ответа перед выдачей, которой у скилла не было: чеклист листа 05 проверяет пост, а не ответ. Листы не тронуты. Смоук шёл на его версии, ручных правок после смоука нет.
- **Кейсы.** D-01 (разбор: пост студии «Нам 3 года») и R-02 (рерайт канцелярского анонса вебинара); запросы дословно из `../eval-set.md`.
- **Руки.** По сабагенту на Opus на кейс и версию: тело `SKILL.md` во вводном файле и пути к листам, как грузится установленный скилл. g1, g2 — на 0.1.2, g3, g4 — на пересобранном скилле.
- **Оценка.** Два слепых грейдера с промптом листа эвалов book-to-skill; блок «Основания» вырезан из ответов до оценки (`strip.py`), две руки одного кейса не попадают к одному грейдеру. Assertions из `../eval-set.md` дословно, кроме четвёртого у R-02: из него убрано требование ссылки на правило номером или формулировкой, потому что номера по новой форме стоят только в блоке, а соответствие правил шагам проверяет отдельный проход ниже.
- **Счёт.** `metrics.py <каталог листов> <ответ.md>...` считает слова, блок оснований, номера правил выше блока и в нём, правила, которых нет в листах, «метод» и годы источников в теле.
- **Проход по соответствию.** Отдельный грейдер взял каждую строку блоков g3 и g4, прочитал поля «Правило» и «Когда не применять» каждого названного правила и решил, говорит ли правило то, что говорит шаг.

## Итоги

| | D-01, разбор | R-02, рерайт |
|---|---|---|
| Номеров правил в теле, 0.1.2 → новая | 14 → 0 | 19 → 0 |
| «Метод» и годы источников в теле | 0 → 0 | 0 → 0 |
| Слов | 487 → 453 | 389 → 386 |
| Блок «Основания» новой версии | 5 строк, 14 номеров | 7 строк, 11 номеров |
| Assertions, 0.1.2 → новая | 5/5 → 5/5 | 4/4 → 4/4 |

- **Выдуманные правила.** Ни в одной руке: каждый номер есть в листах. В новой версии все 25 пар «строка блока ↔ правило» сходятся (D-01 14, R-02 11); шагов без строки нет.
- **Термины.** Конструкты даны вместе со смыслом: «полезное действие — причина, по которой читатель сам захочет его прочитать», «стоп-слова, то есть слова, которые вычёркиваются без потери смысла».
- **Одна мелочь без пометки.** Рерайт R-02 заменил «более 500 интервью» на «больше 500», и ни одно правило из блока этого не требует. Факт не меняется, но это правка, которая не опирается на правило и не помечена.

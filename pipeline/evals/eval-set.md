# Eval-set скилла `glavred`

22 кейса, у каждого 3–5 assertions, проверяемых «да/нет» по тексту выхода. Набор самодостаточен: все тексты постов лежат здесь же, внешних файлов кейсы не требуют.

## Состав набора

| Тип | ID | Сколько | Что проверяет |
|---|---|---|---|
| Диагностические синтетические | D-01 … D-08 | 8 | находит ли скилл заложенное нарушение и на верном ли уровне |
| Рерайт | R-01 … R-04 | 4 | сохранность фактов и голоса автора, обоснование правок |
| Триггер позитивный | T-01, T-02 | 2 | открывается ли скилл по description, когда метод не назван |
| Триггер негативный | T-03 … T-06 | 4 | НЕ открывается ли скилл на чужом запросе |
| Диагностические реальные | RD-01 … RD-04 | 4 | формат выдачи и опора находок на правила листов |

Негативные триггеры T-03 … T-06 добавлены в Task 7: критерий «ложное срабатывание» из `references/04-evals.md` до этого не был измерен, состав набора его не покрывал.

Синтетические посты D-01 … D-08 и R-01, R-02 написаны для этого набора; в каждом D-кейсе 1–2 заложенных нарушения конкретных правил из листов. Реальные посты RD-01 … RD-04, R-03, R-04 — посты пользователя из `tmp/eval-posts/posts.md`, приведены дословно.

Запросы сформулированы словами пользователя, а не словами метода: слова «главред», «Ильяхов», «инфостиль», «полезное действие» в запросах не встречаются нигде.

## Как прогонять

На каждый кейс — два независимых сабагента с чистым контекстом:

- **со скиллом** — в промпт кладётся дословное тело `skills/glavred/SKILL.md` как вводная «у тебя установлен скилл, вот он» плюс абсолютные пути пяти листов `skills/glavred/references/*.md`, которые агент читает по роутингу сам (так работает установленный скилл: тело в контексте, листы читаются по требованию);
- **без скилла** — только запрос кейса, без единого упоминания скилла, метода и того, что это тест; агенту запрещено исследовать репозиторий.

Триггер-кейсы T-01 … T-06 устроены иначе: агент получает только `description` из фронтматтера скилла в списке из пяти описаний (четыре посторонних скилла как дистракторы) и решает, открывать ли что-нибудь. Бейзлайна у триггер-кейсов нет — без скилла открывать нечего, дельта для них не считается. Каждый триггер-кейс прогоняется трижды: срабатывание нестабильно. Позиция `glavred` в списке меняется от прогона к прогону, чтобы не мерить позиционное смещение. Промпты прогона, тексты всех пяти описаний, позиции `glavred` и промпт грейдера — в `.superpowers/sdd/2026-08-13-glavred-skill/eval-runs/trigger-neg-prompt.md`.

Путь `.superpowers/sdd/2026-08-13-glavred-skill/…` — внутренняя рабочая директория сборки (промпты прогонов, выходы грейдеров, отчёты задач): она в `.gitignore` и в репозиторий не входит.

Грейдер работает отдельно, с чистым контекстом, видит запрос, ответ и assertions, не знает, какой ответ из какой руки. Вердикт — JSON с дословной цитатой-доказательством на каждый assertion; нет цитаты — `passed: false`.

## Пороги

- Со скиллом — не меньше 80 % пройденных assertions.
- Дельта над бейзлайном — не меньше 20 п.п.
- Бейзлайн — меньше 70 %.
- Ноль выдуманных фактов в рерайт-кейсах.
- Негативный кейс D-08 — без ложных 🔴.
- Ноль выдуманных правил: каждый номер правила из выходов «со скиллом» существует в листах и по смыслу соответствует находке.
- Ноль ложных срабатываний: ни в одном из двенадцати прогонов негативных триггеров скилл не открывается.

Отдельная история — визы: голубая карта ЕС требует диплом и зарплату выше порога, который каждый год меняется, в Нидерландах есть схема для высококвалифицированных мигрантов, в Германии с 2023 года порог снизили, в Британии нужен спонсорский лицензированный работодатель, и это отсекает почти все стартапы, а в Польше и Чехии проще, но зарплаты ниже, и надо считать, что вам выгоднее в перспективе пяти лет с учётом налогов, которые в Германии съедают до 42%, а в Польше до 32%. Про английский: B2 достаточно для большинства технических ролей, C1 нужен для менеджерских, и главная проблема не грамматика, а то, что на созвоне вы не понимаете индийский и шотландский акценты, поэтому слушайте подкасты с разными акцентами, а не только американские.
